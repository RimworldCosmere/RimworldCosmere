*把镕金术和藏金术拖进边缘世界。*

​

![About](../.github/assets/scadrial/about.png)

*为 RimWorld 重建的金属之艺：镕金术、藏金术，还有>!血金术!<。*

- **镕金术**
    - 全部基础金属和>!神金!<，每种都有自己的能力
    - 迷雾人只能烧一种金属。>!射币者、安抚者、暴徒，诸如此类。!<
    - 迷雾之子全都能烧，前提是你运气够好能抽到一个
    - 燃烧与爆燃，每种金属都带有自己的能力、光环和状态效果
    - 多金属药剂、指向性能力，以及环境效果

- **藏金术**
    - 储存并取回力量、速度、健康或感官
    - 完整的藏金术师能拿到全套金属意识
    - 储存机制，以及一套追踪充能量的界面
    - >!同一种金属上同时拥有镕金与藏金能力的小人可以进行复合。!<

- **>!血金术 - 即将推出!<**
    - >!黑暗、危险，而且完全真实。道德风险自负。仍在开发中。!<

- **基于基因的金属之子**
    - 基因会把镕金与藏金能力传给下一代
    - 适用于玩家繁衍、小人生成和自定义异种

- **觉醒**
    - 压力可能让小人崩溃，然后以金属之子的身份走出来
    - 创伤和某些天气事件会为此进行判定

- **新的特质、想法与需求**
    - 燃烧金属会补充小人的授予
    - 为燃烧、爆燃、光环和压制准备的想法
    - 司卡、贵族与泰瑞斯异种，围绕血统与基因重做

- **场景支持**
    - 灰烬尽逝之前与之后的场景
    - 选择由毁灭与存护，还是由和谐掌管你的世界
    - 与时代相符的异种限制、基因权重和小人生成

​
