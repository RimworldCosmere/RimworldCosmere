*把罗沙搬到边缘世界。引术、与灵缔结的誓约，还有飓风。*

​

![About](../.github/assets/roshar/about.png)

*罗沙，以及在那里活下去要付出什么。*

- **引术**
    - 十种引力分给十个辉骑团，每个团拿到两种以及一枚宝石
    - 缚绳、魂术、再生、幻光、异界行走，以及其余的引力能力
    - 这一切都靠飓光驱动，而飓光消耗得很快

- **纳海尔誓约**
    - 抓住一只灵，留住它，和它缔结
    - 每个团五条誓言。每说出一条，你能容纳的飓光上限就上升，并解锁新能力
    - 违背誓言，誓约就会紧绷，接着出现裂痕，最后断裂

- **碎刃与碎甲**
    - 辉骑之刃，以及需要十次心跳才能召唤出来的死刃
    - 靠飓光运转的碎甲与碎盔

- **飓光与宝石**
    - 碎币、标币和布姆，可以灌注也可以耗尽
    - 球币袋，以及能够劈开的宝心
    - 法器：增幅器、削减器、痛器，以及飓光发电

- **飓风与泣季**
    - 飓风会按固定时间横扫地图。建起真正的掩体，否则就会死人
    - 留在外面的一切都会充能。留在外面的一切也都会死
    - 泣季让飓风停下，飓光也随之断供

- **罗沙社会**
    - 亮眸人与暗眸人，按照纳恩与达恩分级
    - 雅烈席战营、聆听者部族、塔勒纳商人，以及西恩农夫

- **守夜者**
    - 去求一个恩赐。连带着接下诅咒

- **场景**
    - 第四桥、破碎平原、辉光之辞、科林纳的陷落、乌瑞席鲁之围、泣季，以及真正的寂灭

​

![Compatibility](../.github/assets/roshar/compatibility.png)

- 需要 Biotech
- 可与 Ideology、Royalty 和 Anomaly 同时使用
- 为 RimWorld 1.7 构建
- 开局时添加是安全的
- 对中途存档的支持是部分的。想要完整的宝石与资源请开新殖民地

​

![Tips](../.github/assets/roshar/tips.png)

- 尽早建屋顶和真正的掩体。飓风不是布景
- 派辉骑上阵之前，手上备好灌注过的球币或别的飓光来源
- 慎重对待纳海尔誓约。毁约应该是有代价的
- 这些系统还在测试阶段，想体验完整的罗沙请开一局新殖民地
